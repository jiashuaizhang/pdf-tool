# PDF 处理

在本机拆分、合并 PDF。页面在浏览器里预览和勾选，文件不会上传到网络。

## 启动

双击 `start.bat`。

脚本会使用项目里的 `.venv`。如果还没有虚拟环境，会先创建并安装 `requirements.txt` 中的依赖。启动后自动打开：

http://127.0.0.1:8765

关闭弹出的命令行窗口即停止服务。若提示端口 8765 已被占用，先关掉之前打开的窗口。

## 功能

左侧有两个功能，预览和导出方式相同。

- **拆分**：一次选择一个 PDF。默认文件名为「原文件名-摘页」，后缀 `.pdf` 固定，不能改。
- **合并**：可一次添加多个 PDF，也可以继续追加。页面按添加顺序排列。默认文件名为「合并」。

选中文件后：

- 勾选要保留的页面。支持全选、反选。
- 点页面上的展开图标查看大图。预览层右下角的「−」「+」可缩放；按住 Ctrl 再滚动滚轮也可以缩放。单独滚动滚轮只上下翻页。
- 删除只从本次列表里去掉该页，不修改原文件。
- 右下角按钮按当前勾选顺序生成新 PDF，并由浏览器下载。

## 限制

- 只监听本机 `127.0.0.1`。
- 单个文件不超过 300MB，一次添加合计不超过 800MB。
- 一次最多 30 个文件，页面总数不超过 2000。
- 加密的 PDF 无法处理。
